INF 321 - Projeto e Desenvolvimento de Sistemas para a Web

Departamento de Informática - Universidade Federal de Viçosa (UFV)

Professor: Lucas Vegi | Aluno: Rafael Caetité

Sobre a disciplina

A disciplina aborda o desenvolvimento de aplicações web completas, cobrindo tanto o ecossistema front-end (HTML5, CSS3 e JavaScript) quanto a arquitetura e comunicação com sistemas back-end.

Professor: Lucas Vegi

Departamento: Departamento de Informática (DPI / CCE)

Tópicos estudados

Principais conteúdos abordados ao longo do semestre:

  • Arquitetura da Web e protocolo HTTP
  • Estrutura semântica de páginas com HTML5
  • Estilização e layouts com CSS3 (Flexbox e Grid)
  • Design responsivo e acessibilidade
  • Programação client-side com JavaScript
  • Consumo de APIs e comunicação assíncrona
  • Introdução a frameworks e desenvolvimento back-end
